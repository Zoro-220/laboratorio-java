Módulo 1: Herencia en Java

¿Qué es la herencia?
Mecanismo por el cual una clase (subclase) adquiere atributos y métodos de otra (superclase). Representa una relación «es un» (ej. un Gerente es un Empleado). Evita duplicar código.
  • extends: Indica herencia. Java no permite herencia múltiple de clases.
  • protected: Permite que los atributos sean visibles y utilizables directamente por las subclases, pero ocultos para el exterior.
  • super(...): Llama al constructor de la superclase y debe ser la primera instrucción.
  • @Override: Indica que sobrescribes un método heredado. En Java, todas las clases heredan de Object, por lo que podemos sobrescribir el método toString().

Proyecto: EjercicioHerencia (Múltiples Archivos)

Organización del Código:
En IDEs como NetBeans o Eclipse, cada clase pública va en su propio archivo. Aquí veremos cómo Gerente y Vendedor heredan de Empleado, sobrescribiendo el método calcularSalario() y el método toString().

Empleado.java (La Superclase)

package Herencia;

/**
 * @author Aula
 */
public class Empleado {
    protected String nombre;
    protected Double salarioBase;

    public Empleado(String nombre, Double salarioBase) {
        this.nombre = nombre;
        this.salarioBase = salarioBase;
    }
    
    public double calcularSalario(){
        return salarioBase;
    }

    @Override
    public String toString() {
        return "Empleado{" + "nombre=" + nombre + ", salarioBase=" + salarioBase + '}';
    }
}

Gerente.java (Subclase 1)

package Herencia;

/**
 * @author Aula
 */
public class Gerente extends Empleado {
    private double bono;

    public Gerente(double bono, String nombre, Double salarioBase) {
        super(nombre, salarioBase);
        this.bono = bono;
    }
    
    @Override
    public double calcularSalario(){
        return super.calcularSalario() + bono;
    }
    
    @Override
    public String toString(){
        return "Gerente: " + super.toString();
    }
}

Vendedor.java (Subclase 2)

package Herencia;

/**
 * @author Aula
 */
public class Vendedor extends Empleado {
    private double comision; 
    private double ventas;

    public Vendedor(double comision, double ventas, String nombre, Double salarioBase) {
        super(nombre, salarioBase);
        this.comision = comision;
        this.ventas = ventas;
    }

    public double CalcularComision(){
        return ventas * comision;
    }
    
    @Override
    public double calcularSalario(){
        return super.calcularSalario() + CalcularComision();
    }
    
    @Override
    public String toString(){
        return "Vendedor: " + super.toString();
    }
}

Main.java (El Ejecutor)

package Herencia;

/**
 * @author Aula
 */
public class Main {
    public static void main(String[] args) {
        Empleado empleado = new Empleado("Juan", 500000.0);
        Gerente gerente = new Gerente(100000.0, "Pablo", 500000.0);
        Vendedor vendedor = new Vendedor(0.05, 100000.0, "Gabriel", 500000.0);
        
        System.out.println(empleado.toString());
        System.out.println(gerente.toString());        
        System.out.println(vendedor.toString());        
    }
}

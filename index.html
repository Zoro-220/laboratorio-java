Introducción a Java

¿Qué es Java?
Java es un lenguaje de programación orientado a objetos, robusto y multiplataforma. Su principio fundamental es "Escribe una vez, ejecuta en cualquier lugar", gracias a que el código se compila en bytecode y es interpretado por la Máquina Virtual de Java (JVM).

Características Principales

  • Orientado a Objetos: En Java todo gira en torno a Clases y Objetos. Esto nos permite modelar el mundo real en nuestro código.
  • Tipado Estático: A diferencia de Python o JavaScript, en Java debes declarar explícitamente qué tipo de dato almacenará una variable (ej. int, String).
  • Garbage Collector: Java gestiona la memoria de tu computador por ti, eliminando automáticamente los objetos que el programa ya no está utilizando.

Estructura de un Programa

// Todo código en Java debe vivir dentro de una clase
public class HolaMundo {
    
    // El método 'main' es el punto de entrada de la aplicación
    public static void main(String[] args) {
        
        int semestre = 4;
        String mensaje = "¡Bienvenidos a Programación Avanzada!";
        
        System.out.println(mensaje);
        System.out.println("Estamos listos para el semestre " + semestre);
    }
}
Guía del Profesor:
Antes de avanzar a los temas complejos como interfaces gráficas o arquitectura de software, asegúrate de dominar bien la creación de clases, el uso del método main y cómo compilar tu código. Una vez que te sientas seguro, pasa al Módulo 1 en el menú superior.

Retos de Programación Práctica

Abre tu IDE (Eclipse, NetBeans o VS Code) y resuelve los siguientes ejercicios:

Reto 1: Calculadora Básica
Crea una clase llamada Calculadora. Dentro del método main, declara dos variables de tipo int (por ejemplo, a = 15 y b = 20). Calcula la suma de ambas y muestra en consola el mensaje: "El resultado de la suma es: 35".
Reto 2: Perfil del Estudiante
Crea un programa que declare tres variables: un String para tu nombre, un int para tu semestre actual y un double para tu promedio de notas. Imprime un párrafo de presentación usando esas variables concatenadas con texto (usando el símbolo +).

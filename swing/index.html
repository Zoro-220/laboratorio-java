Módulo 2: Swing y Experiencia de Usuario (UX)

Librería Swing
Swing permite crear aplicaciones de escritorio con interfaces de usuario. Usamos elementos como JFrame (ventana base), JPanel (contenedores) y definimos su estructura mediante Layouts.

Conceptos Claves y Componentes

  • JFrame: Constantes como EXIT_ON_CLOSE determinan que el programa finalice al cerrar la ventana.
  • Layouts: Organizan la vista. BorderLayout (centro y bordes), GridLayout (matriz rígida) y FlowLayout.
  • Eventos: Usamos ActionListener (a menudo mediante lambdas e -> { ... } para dar vida a los botones.

Código Explicado: UXIntroductionApp

import javax.swing.*;
import java.awt.*;

public class UXIntroductionApp {
  public static void main(String[] a) {
    JFrame frame = new JFrame("UX Introduction App");
    frame.setSize(400, 300);
    frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
    
    // Configuramos una matriz de 3 filas y 2 columnas
    JPanel panel = new JPanel();
    panel.setLayout(new GridLayout(3, 2, 10, 10));
    
    JTextField nameField = new JTextField();
    JButton button = new JButton("Submit");

    // Damos interactividad al botón
    button.addActionListener(e -> {
        String name = nameField.getText();
        if(name.isBlank()) {
            JOptionPane.showMessageDialog(frame, "Ingrese su nombre", "Error", JOptionPane.WARNING_MESSAGE);
        } else {
            JOptionPane.showMessageDialog(frame, "Bienvenido, " + name);
        }
    });

    panel.add(new JLabel("Nombre:"));
    panel.add(nameField);
    panel.add(new JLabel()); // Celda vacía para empujar el botón
    panel.add(button);

    frame.add(panel);
    frame.setVisible(true);
  }
}
Análisis del Profesor:
Este ejercicio demuestra cómo ensamblar componentes. Empleamos un GridLayout para ordenar la etiqueta, el campo de texto y el botón. Lo más importante de UX aquí es el ActionListener y la función isBlank() (Java 11+), que usamos para validar que el usuario no envíe un campo vacío antes de procesar sus datos.

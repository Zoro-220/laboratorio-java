Módulo 3: Splash Screens, Hilos y Formularios

¿Qué es un Splash Screen?
Es una pantalla de bienvenida que aparece antes de que la aplicación principal se muestre. En Swing, esto se logra utilizando JWindow (una ventana sin bordes ni botones de cerrar) en lugar de JFrame.
  • JWindow y JFrame: JWindow crea la ventana "desnuda" para la carga, y dispose() la destruye de la memoria para dar paso a tu JFrame principal.
  • Anidamiento de Layouts: Para hacer formularios complejos, puedes poner un layout dentro de otro. Por ejemplo, un BoxLayout vertical que contenga varios JPanel con FlowLayout horizontal.
  • SwingUtilities.invokeLater: Swing no es "thread-safe" (seguro para hilos). Si actualizas un texto desde un hilo secundario (Thread), debes envolverlo en esta instrucción para que Swing lo dibuje de forma segura.

Proyecto: VentanaConJWindows

Análisis del Profesor:
En este proyecto simulamos la carga de un sistema. VentanaSplash usa un Thread para pausar el tiempo (Thread.sleep) y cambiar el texto dinámicamente. Al terminar, se cierra sola y abre el formulario de registro (VentanaPrincipal), el cual está construido apilando varios paneles horizontales dentro de una columna principal.

VentanaSplash.java (Pantalla de Carga)


import java.awt.*;
import javax.swing.*;

public class VentanaSplash extends JWindow {
    private JLabel textoCarga;
    
    public VentanaSplash() {
        prepararInterfaz();
    }
    
    public void prepararInterfaz() {
        JPanel contenido = (JPanel) getContentPane();
        contenido.setBackground(Color.WHITE);
        contenido.setBorder(BorderFactory.createLineBorder(new Color(50,50,50),2));
        
        textoCarga = new JLabel("Iniciando aplicacion...", SwingConstants.CENTER);
        contenido.add(textoCarga, BorderLayout.CENTER);
        setSize(500,500);
        setLocationRelativeTo(null);
    }
    
    public void mostarYCargar() {
        setVisible(true);
        // Creamos un hilo secundario para no congelar la ventana
        new Thread(() -> {
            try {
                actualizarEstado("Cargando módulos...");
                Thread.sleep(1000);

                actualizarEstado("Conectando a la base de datos...");
                Thread.sleep(1500);

                actualizarEstado("Iniciando interfaz...");
                Thread.sleep(800);
            } catch (InterruptedException e) {
                e.printStackTrace();
            }

            // Al terminar la carga, cerramos el splash y abrimos el JFrame de forma segura
            SwingUtilities.invokeLater(() -> {
                dispose(); 
                VentanaPrincipal principal = new VentanaPrincipal();
                principal.setVisible(true);
            });
        }).start();
    }

    private void actualizarEstado(String mensaje) {
        // Actualizamos la GUI desde el hilo secundario de forma segura
        SwingUtilities.invokeLater(() -> textoCarga.setText(mensaje));
    }
}

VentanaPrincipal.java (Formulario de Registro)


import java.awt.*;
import javax.swing.*;

public class VentanaPrincipal extends JFrame {
    
    private JTextField nombretxt, apellidotxt, correotxt, carreratxt, modulotxt;
    private JLabel nombrelbl, apellidolbl, correolbl, carreralbl, modulolbl, unolbl, doslbl;
    
    public VentanaPrincipal() {
        setTitle("Ficha de Registro");
        setSize(500, 500);
        setDefaultCloseOperation(EXIT_ON_CLOSE);
        setLocationRelativeTo(null);
        Componentes();
    }
    
    public void Componentes() {
        JPanel panelPrincipal = new JPanel();
        // BoxLayout alinea todos los sub-paneles en una columna vertical (Y_AXIS)
        panelPrincipal.setLayout(new BoxLayout(panelPrincipal, BoxLayout.Y_AXIS));
        
        // --- Panel Título ---
        JPanel unotexto = new JPanel(new FlowLayout(FlowLayout.CENTER, 20, 5));
        unolbl = new JLabel("Datos del estudiante", SwingConstants.CENTER);
        unotexto.add(unolbl);
        panelPrincipal.add(unotexto);
        
        // --- Panel Nombre ---
        JPanel nombre = new JPanel(new FlowLayout(FlowLayout.CENTER, 20, 0));
        nombrelbl = new JLabel("Nombre:", SwingConstants.LEFT);
        nombrelbl.setFont(new Font("Arial", Font.PLAIN, 18));
        nombretxt = new JTextField();
        nombretxt.setPreferredSize(new Dimension(250,50));
        nombre.add(nombrelbl);
        nombre.add(nombretxt);
        panelPrincipal.add(nombre); 
        
        // (Los paneles de Apellido, Correo y Carrera siguen la misma estructura)
        
        // --- Panel Módulo (Solo lectura) ---
        JPanel modulo = new JPanel(new FlowLayout(FlowLayout.CENTER, 20, 0));
        modulolbl = new JLabel("Módulo:", SwingConstants.LEFT);
        modulolbl.setFont(new Font("Arial", Font.PLAIN, 18));
        modulotxt = new JTextField();
        modulotxt.setText("Programación Avanzada");
        modulotxt.setPreferredSize(new Dimension(250,50));
        modulotxt.setEditable(false); // Evita que el usuario edite este campo
        modulo.add(modulolbl);
        modulo.add(modulotxt);
        panelPrincipal.add(modulo);

         JPanel dostexto = new JPanel(new FlowLayout(FlowLayout.CENTER , 20 , 0));
        doslbl = new JLabel("Complete todos los campos", SwingConstants.CENTER);
        dostexto.add(doslbl);
        panelPrincipal.add(dostexto);
        
        this.add(panelPrincipal);
    }
}

Main.java (El Ejecutor)


import javax.swing.*;

public class Main {
    public static void main(String[] args) {
        // Iniciamos la interfaz en el hilo de eventos de Swing
        SwingUtilities.invokeLater(() -> {
            VentanaSplash splash = new VentanaSplash();
            splash.mostarYCargar();
        });
    }
}

Retos de Programación Práctica

Abre tu IDE, ejecuta el proyecto de las ventanas y realiza las siguientes modificaciones:

Reto 1: Botón de Envío
En la clase VentanaPrincipal, crea un nuevo JPanel al final. Agrégale un JButton que diga "Guardar". Añádele un ActionListener que valide si nombretxt.getText() está vacío. Si está vacío, muestra un mensaje de error; si tiene texto, muestra un JOptionPane que diga "Estudiante guardado exitosamente".
Reto 2: Barra de Progreso Visual
En la clase VentanaSplash, investiga cómo añadir un JProgressBar debajo del texto de carga. Configúralo de 0 a 100, y haz que su valor (setValue(...)) aumente a medida que pasan los Thread.sleep().
